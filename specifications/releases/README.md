# Specifications — Releases

## Overview
Specifies the content of platform releases: what each release includes and the criteria for shipping it.

## Purpose
To define release scope and acceptance for the platform.

## Responsibilities
- Record the normative releases specifications for the platform.
- Stay consistent with the vision and the ratified decisions.
