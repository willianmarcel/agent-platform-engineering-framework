# Specification Images

## Overview
Holds image assets specific to the Specification Framework.

## Purpose
To store rendered diagram exports and illustrations for the framework.

## Responsibilities
- Store rendered images the framework documents reference.
- Keep media beside the framework rather than in unrelated locations.

## Contents
- Rendered exports of the framework's Mermaid diagrams, and illustrations.

## Out of Scope
- Editable diagram sources — those are the Mermaid blocks in the framework documents.
- Shared, cross-cutting media — those live in [`../../assets/`](../../assets/).

## Relationships
- [Specification Framework](../SPECIFICATION_FRAMEWORK.md) — the documents these images support.

## References
- [Writing Guide](../../handbook/WRITING_GUIDE.md) — how images are referenced.

## Conventions
- Prefer vector formats; the diagrams themselves live as diagram-as-code in the documents.
