# Specification Templates

## Overview
Holds the normative, implementation-independent templates of the Specification Framework.

## Purpose
To keep every specification consistent by providing the required structure per category.

## Responsibilities
- Provide the canonical structure for each specification category and reusable section.
- Stay implementation-independent and consistent with the framework.

## Contents
- Full templates: product, capability, API, architecture, domain, and runtime specifications.
- Section templates: ADR reference, acceptance criteria, review checklist, completion checklist.

## Out of Scope
- Filled-in specifications (those live in the relevant specification area).
- Any technology, vendor, or language.

## Relationships
- [Specification Taxonomy](../SPECIFICATION_TAXONOMY.md) — the categories these templates serve.
- [Base specification template](../../templates/specification/) — the repository's base template.

## References
- [Specification Framework](../SPECIFICATION_FRAMEWORK.md) — the methodology these templates realize.

## Conventions
- A template is a blank form with guidance, not an example; examples live in [`../examples/`](../examples/).
