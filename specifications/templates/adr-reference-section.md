# Template — ADR Reference Section

A reusable, normative section template of the APEF
[Specification Framework](../SPECIFICATION_FRAMEWORK.md): the section by which a specification references its governing decisions. It is included within a full
specification rather than used alone.

**How to use:** For each significant decision: the ADR identifier, its subject, and how it shapes this specification.

## Conventions
- Implementation-independent; names no technology.
- Consistent with [Traceability](../SPECIFICATION_TRACEABILITY.md),
  [Review](../SPECIFICATION_REVIEW.md), and [Completion](../SPECIFICATION_COMPLETION.md).
