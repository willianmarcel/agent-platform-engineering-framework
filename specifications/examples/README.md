# Specification Examples

## Overview
Holds conceptual examples that demonstrate correct specification methodology.

## Purpose
To show how the framework is applied, illustrating methodology rather than any product.

## Responsibilities
- Provide technology-neutral, conceptual examples of specification usage.
- Stay aligned with the templates and the framework.

## Contents
- Conceptual examples (for example, a Product Specification and a traceability example).

## Out of Scope
- Real, product-specific specifications.
- Any technology, vendor, or language.

## Relationships
- [Specification Templates](../templates/) — the forms these examples instantiate.
- [Specification Framework](../SPECIFICATION_FRAMEWORK.md) — the methodology illustrated.

## References
- [Specification Framework](../SPECIFICATION_FRAMEWORK.md).

## Conventions
- Examples illustrate methodology only and never define a specific technology.
