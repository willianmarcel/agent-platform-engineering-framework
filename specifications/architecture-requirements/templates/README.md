# Architecture Requirements — Templates

## Overview
Holds the normative templates of the Architecture Requirements specification library.

## Purpose
To keep every Architecture Requirements specification consistent by providing the required structure.

## Responsibilities
- Provide the canonical structure for this library's specification types.
- Stay implementation-independent and consistent with the framework.

## Contents
- The [Architecture Requirements specification template](./architecture-requirements-specification-template.md).

## Out of Scope
- Filled-in specifications; any technology, vendor, or language.
