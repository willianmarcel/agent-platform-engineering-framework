# Specifications — Architecture Requirements

## Overview
Holds normative architecture requirements: the constraints and quality attributes the architecture models must satisfy.

## Purpose
To state what the architecture must achieve, separate from how it is drawn.

## Responsibilities
- Record the normative architecture requirements specifications for the platform.
- Stay consistent with the vision and the ratified decisions.

## Contents
- Architecture requirements, quality attributes, constraints, and fitness functions.
