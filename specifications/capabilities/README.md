# Specifications — Capabilities

## Overview
Specifies the capabilities the platform provides, independent of how they are implemented.

## Purpose
To define the discrete, valuable things the platform can do.

## Responsibilities
- Record the normative capabilities specifications for the platform.
- Stay consistent with the vision and the ratified decisions.

## Contents
- Capability definitions, their inputs and outputs, acceptance criteria, and dependencies.
