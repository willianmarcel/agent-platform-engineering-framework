# Specifications — Roadmap

## Overview
Specifies the platform roadmap as structured artifacts: sequenced capabilities and their dependencies.

## Purpose
To make the platform's plan explicit and dependency-aware.

## Responsibilities
- Record the normative roadmap specifications for the platform.
- Stay consistent with the vision and the ratified decisions.

## Contents
