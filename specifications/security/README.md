# Specifications — Security

## Overview
Specifies the platform's security requirements: threats, controls, and assurances that must hold.

## Purpose
To make security requirements explicit and verifiable.

## Responsibilities
- Record the normative security specifications for the platform.
- Stay consistent with the vision and the ratified decisions.

## Contents
- Threat models, security requirements, control specifications, and compliance criteria.

## Out of Scope
- Secrets, credentials, or API keys.
- [Narrative security teaching.](../../handbook/15-security/)
