# Specifications — Discovery

## Overview
Holds discovery artifacts that precede formal specification: research, problem framing, and hypotheses.

## Purpose
To inform what to build before intent is fixed as a specification.

## Responsibilities
- Record the normative discovery specifications for the platform.
- Stay consistent with the vision and the ratified decisions.

## Contents
- Problem statements, user and stakeholder research, opportunity assessments, and discovery findings.

## Out of Scope
- Finalized normative specifications — they graduate into the relevant specification directory.
- Application, API, frontend, or backend code.
