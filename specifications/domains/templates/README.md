# Domain — Templates

## Overview
Holds the normative templates of the Domain specification library.

## Purpose
To keep every Domain specification consistent by providing the required structure.

## Responsibilities
- Provide the canonical structure for this library's specification types.
- Stay implementation-independent and consistent with the framework.

## Contents
- The [Domain specification template](./domains-specification-template.md).

## Out of Scope
- Filled-in specifications; any technology, vendor, or language.

## Relationships
- [Domain Specifications](../DOMAIN_SPECIFICATIONS.md) — the library these templates serve.
- [Specification Templates](../../templates/) — the framework's base templates.

## References
- [Specification Framework](../../SPECIFICATION_FRAMEWORK.md).

## Conventions
- A template is a blank form with guidance, not an example.
