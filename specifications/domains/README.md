# Specifications — Domains

## Overview
Specifies the platform's domains, their boundaries, and their ubiquitous language, following Domain-Driven Design.

## Purpose
To establish clear bounded contexts and shared terminology.

## Responsibilities
- Record the normative domains specifications for the platform.
- Stay consistent with the vision and the ratified decisions.

## Contents
- Domain definitions, bounded contexts, context maps, and domain glossaries.
