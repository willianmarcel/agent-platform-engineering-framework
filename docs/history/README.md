# Milestone & Process History

This directory holds APEF's internal engineering-milestone record — the milestone summaries,
compliance reports, outstanding-decision logs, next-milestone proposals, and completion reports
produced while the framework was being built (Bootstrap, EC-1, EC-2, EC-3).

It is **governance history, not published framework guidance.** It is kept for auditability and
traceability but is intentionally separated from the framework's published surface (the Handbook,
Specifications, Execution Framework, ADR Library, Architecture Modeling Framework, and Governance
package), per the AR-001 review recommendation to keep the internal process trail out of the
published corpus.

For the current framework, start at the [Framework Map](../FRAMEWORK_MAP.md) and
[Framework Index](../FRAMEWORK_INDEX.md).
