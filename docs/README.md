# Docs — Documentation Derived From the Handbook

## Overview
This directory holds documentation rendered or curated from the handbook. It is generated output, not an authoring surface: the handbook is edited, and docs is derived from it.

## Purpose
To present handbook content in publication-ready form for human readers.

## Responsibilities
- Host rendered or curated documentation, navigation, and indexes produced from the handbook.
- Carry documentation-build configuration if a static site generator is adopted.

## Contents
- Rendered or publication-oriented documentation derived from the handbook.
- Documentation tooling configuration, when introduced.

## Out of Scope
- [The single source of truth — that is the handbook, which is authored, not generated.](../handbook/)
- [Binary design assets.](../assets/)
- Application, API, frontend, or backend code.

## Relationships
- [Handbook](../handbook/) — the authored source of truth this directory renders or curates.
