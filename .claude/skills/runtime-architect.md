# Skill — Runtime Architect

A specialist engineering-role skill of the APEF Execution Framework. Full definition —
mission, responsibilities, inputs, outputs, decision boundaries, and collaboration — is in the
[Skill Catalog](../SKILL_CATALOG.md).

- **Mission:** Design how agents and workflows execute within runtime boundaries.
- **Owns:** Runtime execution
- **Defers:** Authoring, provision, governance, persistence

This skill embodies an engineering role (a persona in Foundation terms). It carries decision
authority within its boundary and collaborates with the other skills per the Skill Catalog.
