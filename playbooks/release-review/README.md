# Playbook — Release Review

## Overview
A repeatable procedure for reviewing a release candidate before it is cut and published.

## Purpose
To make this review repeatable and its outcomes consistent regardless of who runs it.

## Responsibilities
- Define the procedure's trigger, steps, decision criteria, and output.
- Enforce the relevant quality gates.

## Contents
- Release-review steps, scope and quality-gate verification, and the go/no-go record.
