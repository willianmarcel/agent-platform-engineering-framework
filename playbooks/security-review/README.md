# Playbook — Security Review

## Overview
A repeatable procedure for reviewing designs and changes for security risk, threats, and control adequacy.

## Purpose
To make this review repeatable and its outcomes consistent regardless of who runs it.

## Responsibilities
- Define the procedure's trigger, steps, decision criteria, and output.
- Enforce the relevant quality gates.

## Contents
- Security review steps, a threat-review checklist, severity criteria, and the review record.

- Secrets or exploit details.
