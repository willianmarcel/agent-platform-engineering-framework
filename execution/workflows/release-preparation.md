# Workflow — Release Preparation

An end-to-end workflow of the APEF Execution Framework. Full definition — stages, orchestrated
commands and skills, and gates — is in the [Workflow Catalog](../WORKFLOW_CATALOG.md).

- **Purpose:** Bring a change set to a considered, ready release.
- **Orchestrates:** [commands](../COMMAND_CATALOG.md) executed by [skills](../SKILL_CATALOG.md),
  gated by [quality gates](../QUALITY_GATES.md) at every stage.
- **Authority:** the Handbook, principally
  [Chapter 04 — Development Methodology](../../handbook/04-development-methodology/CHAPTER.md).

This workflow defines process, not implementation.
