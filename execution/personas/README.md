# execution/personas — AI Collaborator Roles

## Overview
This directory defines the personas an AI collaborator can adopt when working on APEF, such as an architect, security reviewer, or technical writer.

## Purpose
To set scope, tone, and standards so AI contributions match the role they play.

## Responsibilities
- Describe role-specific expectations, constraints, and review criteria.
- Ensure AI assistance is appropriate to the task at hand.

## Contents
- Persona definition files, one per role, once the Engineering phase authors them.

## Out of Scope
- [Commands.](../commands/)
- [Workflows.](../workflows/)
- Secrets, credentials, or API keys.
- Application, API, frontend, or backend code.

## Relationships
