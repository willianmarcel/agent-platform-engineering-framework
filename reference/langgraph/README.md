# Reference — LangGraph

## Overview
This directory holds structured study notes on LangGraph. LangGraph models agent applications as explicit graphs of nodes and edges with durable state.

## Purpose
We study LangGraph because graph-based orchestration and persistent state are central concerns for any serious runtime platform.
