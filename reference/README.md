# Reference — External Framework Studies

## Overview
This directory collects structured study notes on external agent frameworks and platforms, capturing what each does well, its trade-offs, and which ideas are worth adopting, adapting, or avoiding.

## Purpose
To design APEF with informed awareness of the ecosystem.

## Responsibilities
- Provide honest, engineering-grade analysis of relevant external technologies.
- Explain why each technology is studied and what APEF can learn from it.
