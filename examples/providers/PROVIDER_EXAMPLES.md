# Provider Examples

The worked provider examples of the APEF. They demonstrate provider abstraction — depending on a capability rather than a supplier — as a neutral artifact that names no provider whatsoever.

These examples demonstrate APEF concepts owned by [09](../../handbook/09-provider-platform/CHAPTER.md). They are **non-executable** and
**technology-neutral**: they name no vendor, product, framework, SDK, or implementation detail,
per the Architecture Board's permanent rule that examples demonstrate APEF concepts without
depending on any external technology. The directory [`README.md`](README.md) is a frozen
Foundation artifact and is unchanged; this document is the module entry point.

## Examples

- [Illustrative Provider Integration (behind the abstraction)](./example-provider-integration.md) — demonstrates provider abstraction, model catalog, routing, cost/latency awareness, provider independence, vendor neutrality (all 09).

## Conventions

- Non-executable artifacts and models only (specifications, structured definitions, diagrams,
  decision aids); never code, and never a specific technology.
- Concepts are referenced from their owning chapters, never redefined.
