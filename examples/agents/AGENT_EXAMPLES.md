# Agent Examples

The worked agent examples of the APEF. They demonstrate how an agent is conceived and defined using APEF concepts — its intent, the job it serves, the capabilities and abstract provider intelligence it draws on, and its runtime lifecycle — as a neutral artifact, never as code or a product.

These examples demonstrate APEF concepts owned by [07](../../handbook/07-runtime-platform/CHAPTER.md), [08](../../handbook/08-builder-platform/CHAPTER.md), [02](../../handbook/02-product-thinking/CHAPTER.md). They are **non-executable** and
**technology-neutral**: they name no vendor, product, framework, SDK, or implementation detail,
per the Architecture Board's permanent rule that examples demonstrate APEF concepts without
depending on any external technology. The directory [`README.md`](README.md) is a frozen
Foundation artifact and is unchanged; this document is the module entry point.

## Examples

- [Illustrative Assistant Agent](./example-assistant-agent.md) — demonstrates agent intent and lifecycle (07), agent assembly (08), the job/outcome it serves (02), provider abstraction (09), governance (11).

## Conventions

- Non-executable artifacts and models only (specifications, structured definitions, diagrams,
  decision aids); never code, and never a specific technology.
- Concepts are referenced from their owning chapters, never redefined.
