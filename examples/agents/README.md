# Examples — Agents

## Overview
This directory holds worked, non-executable reference examples of agents that demonstrate how to apply the framework's patterns to a single agent.

## Purpose
To make the relevant concepts concrete and give teams a starting point to adapt.

## Responsibilities
- Demonstrate correct application of the framework's patterns and templates.
- Stay aligned with current specifications and templates.

## Contents
- Illustrative examples expressed as specifications, DSL, JSON, YAML, architecture, diagrams, configuration, or decision trees.

## Out of Scope
- Production or executable application code of any kind.
- [Blank templates.](../../templates/)
- Secrets, credentials, or API keys.

## Relationships

## Conventions
- Examples never contain executable application code; they contain artifacts and models only.
