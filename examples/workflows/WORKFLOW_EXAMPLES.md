# Workflow Examples

The worked workflow examples of the APEF. They demonstrate how a workflow composes coordinated work at design time, and how its execution is delegated to the runtime — as a neutral composition, never an implementation.

These examples demonstrate APEF concepts owned by [08](../../handbook/08-builder-platform/CHAPTER.md), [07](../../handbook/07-runtime-platform/CHAPTER.md). They are **non-executable** and
**technology-neutral**: they name no vendor, product, framework, SDK, or implementation detail,
per the Architecture Board's permanent rule that examples demonstrate APEF concepts without
depending on any external technology. The directory [`README.md`](README.md) is a frozen
Foundation artifact and is unchanged; this document is the module entry point.

## Examples

- [Illustrative Review Workflow](./example-review-workflow.md) — demonstrates workflow composition (08), design-time vs run-time boundary (08/07), human-in-the-loop (17).

## Conventions

- Non-executable artifacts and models only (specifications, structured definitions, diagrams,
  decision aids); never code, and never a specific technology.
- Concepts are referenced from their owning chapters, never redefined.
