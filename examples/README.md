# Examples — Worked Reference Examples

## Overview
This directory holds worked, illustrative examples that show how APEF's concepts come together. Examples are expressed as artifacts and models, never as executable code.

## Purpose
To make abstract specifications concrete and give teams a starting point to learn from.

## Responsibilities
- Demonstrate correct application of the framework's patterns and templates.
- Stay aligned with current specifications and templates.

- [agents](agents/)
- [workflows](workflows/)
- [providers](providers/)
- [plugins](plugins/)
- [supervisors](supervisors/)
- [evaluations](evaluations/)

## Out of Scope
- Production or executable application code of any kind.
- [Blank templates.](../templates/)
- Secrets, credentials, or API keys.

## Relationships
- [Templates](../templates/) — the blank forms these examples instantiate.
- [Specifications](../specifications/) — the intent these examples illustrate.
