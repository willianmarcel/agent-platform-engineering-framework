# Bootstrap — Governance of the Framework Itself

## Overview
The bootstrap directory governs how APEF is built and evolved: the master plan, the ratified decisions, the roadmap, and the engineering, repository, quality, release, and workflow documents that steer every other part of the framework.

## Purpose
To be the authoritative source of how work proceeds — the constitution and process for constructing the framework.

## Responsibilities
- Hold the governing plan, decisions, and process for building the framework.
- Define the phases, quality gates, and release process the framework follows.

- [MASTER_PLAN.md](MASTER_PLAN.md) — the governing plan (the constitution).

## Out of Scope
- Product or platform specifications and architecture — those have their own directories.
- Application, API, frontend, or backend code.
