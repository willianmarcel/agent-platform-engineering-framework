# Repository Guide

## Purpose
The Repository Guide explains how the APEF repository is organized and how to work
within it: where each kind of content lives, how directories relate, and how to find
or place an artifact correctly.

## Contents
- A map of the top-level directories and what each is for.
- The rules that govern where content belongs (summarizing each directory's README).
- Naming, numbering, and cross-linking conventions used across the repository.
- Guidance for adding new directories or artifact types without eroding structure.

## Relationships
It operationalizes the structure mandated by [`MASTER_PLAN.md`](MASTER_PLAN.md) and
complements [`ENGINEERING_GUIDE.md`](ENGINEERING_GUIDE.md). Each directory's own
`README.md` remains the local source of truth; this guide ties them together.

## Current state
Purpose-defined during Foundation. The full guide is authored in the Engineering phase,
once the structure has settled.
