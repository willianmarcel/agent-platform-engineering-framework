# Template — Task

A blank form for a **task**: the smallest unit of tracked work, a single concrete step within a
story. Copy it to author a task; populate every section (no placeholders). Completed tasks live in
[`specifications/backlog/`](../../specifications/backlog/). Author the *what* and *why*, never the
*how*; name no technology.

## 1. Identity
- **Title** — the task's name, stated as an action.
- **Parent story** — link to the owning story.
- **Status** — To Do | In Progress | Done.

## 2. Definition of done
The specific, checkable condition that makes this task complete.

## 3. Scope
What the task covers; what it explicitly does not.

## 4. Dependencies
Any task or artifact that must precede this one.

## 5. Traceability
Link to the parent story and the
[Traceability model](../../specifications/SPECIFICATION_TRACEABILITY.md).

## Conventions
- One concrete step; an unambiguous definition of done; no technology named.
