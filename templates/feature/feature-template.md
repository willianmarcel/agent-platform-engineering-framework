# Template — Feature

A blank form for a **feature**: a coherent unit of value within an epic, decomposable into stories.
Copy it to author a feature; populate every section (no placeholders). Completed features live in
[`specifications/backlog/`](../../specifications/backlog/). Author the *what* and *why*, never the
*how*; name no technology.

## 1. Identity
- **Title** — the feature's name.
- **Parent epic** — link to the owning epic.
- **Owning authority** — the single role accountable for the feature.
- **Status** — Proposed | Accepted | In Progress | Done.

## 2. Value
The user or platform value this feature delivers, and for whom.

## 3. Scope
- **In scope** — the behavior the feature provides.
- **Out of scope** — what it excludes.

## 4. Child stories
The stories that compose this feature, as links.

## 5. Acceptance criteria
Measurable, verifiable criteria that determine the feature is satisfied.

## 6. Dependencies
Upstream features/capabilities required; downstream work that depends on this.

## 7. Traceability
Links to the parent epic, the capability it realizes, and the
[Traceability model](../../specifications/SPECIFICATION_TRACEABILITY.md).

## Conventions
- One owning authority; measurable acceptance criteria; no technology named.
