# Chapter 08 — Images

## Overview
Holds image assets specific to Chapter 08 (Builder Platform).

## Purpose
To store the chapter's own images close to the chapter that uses them.

## Responsibilities
- Store image assets referenced by this chapter.
- Keep chapter-specific media beside the chapter rather than in unrelated locations.

## Contents
- Image files used by this chapter (for example, exported diagram renders or illustrations).

## Out of Scope
- Editable diagram sources — those live in [`architecture/`](../../../architecture/).
- Shared, cross-cutting media — those live in [`assets/`](../../../assets/).

## Relationships
- [Chapter 08 content](../CHAPTER.md) — the chapter these images support.
- [Architecture models](../../../architecture/) — the source of diagrams rendered here.

## References
- [Writing Guide](../../WRITING_GUIDE.md) — how chapters reference images.

## Conventions
- Prefer vector formats; reference images with relative links from the chapter content.
