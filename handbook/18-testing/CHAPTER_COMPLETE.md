## Chapter Objective

Define testing — the discipline that verifies the platform's software is correct — kept strictly distinct from AI evaluation, which is owned exclusively by Chapter 16.

## Scope

- **In scope:** testing strategy; unit, integration, end-to-end, and contract testing; runtime, platform, and agent testing; regression testing, test automation, the test pyramid, and test quality.
- **Out of scope (delegated to owning chapters):** AI quality evaluation (Chapter 16); the definition of done testing helps satisfy (Chapter 04); and any testing tool, framework, or technology.

## Concepts Owned

Chapter 18 is the authoritative source for: Testing Strategy, Unit Testing, Integration Testing, End-to-End Testing, Contract Testing, Runtime Testing, Platform Testing, Agent Testing, Regression Testing, Test Automation, Test Pyramid, Test Quality. Future chapters may
reference these but must never redefine them.
