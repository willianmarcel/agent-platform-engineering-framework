# Chapter 27 — Evaluation-Driven Development

## Overview
Establishes Evaluation-Driven Development as the peer of Specification-Driven Development for non-deterministic, model-dependent behavior.

## Purpose
To make evaluation gate every behavior-shaping change, so agentic behavior is measured and improved on evidence.
