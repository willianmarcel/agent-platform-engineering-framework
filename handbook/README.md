# Handbook — The APEF Engineering Handbook

## Overview
The handbook is the narrative, book-like explanation of the framework, organized as numbered chapters from vision and principles through each platform concern to the glossary. It is the single source of truth from which published documentation is derived.

## Purpose
To teach the concepts, principles, and architecture behind AI Agent Platforms in a stable reading order.

## Responsibilities
- Explain the framework's concepts and connect them to specifications, architecture, templates, and examples.
- Serve as the authored source of truth that the docs directory renders or curates.

## Contents
- One directory per chapter (00–21), each with a README describing the chapter's scope.

## Out of Scope
- [Normative specifications.](../specifications/)
- [Diagram sources.](../architecture/)
- Application, API, frontend, or backend code.

## Relationships
- [Docs](../docs/) — renders or curates handbook content; the handbook is authored, docs is derived.
- [Specifications](../specifications/) — the normative counterpart to the handbook's prose.

## References
- [Master Plan](../bootstrap/MASTER_PLAN.md) — the constitution governing the framework
- [Architecture Decisions](../bootstrap/ARCHITECTURE_DECISIONS.md) — the ratified Foundation decision record

## Conventions
- Chapter directories exist and each README explains the chapter's scope; chapter content is written in the Engineering phase.
