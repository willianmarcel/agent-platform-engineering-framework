# Security Policy

APEF is a documentation and engineering framework and ships no executable services.
"Security" here concerns the integrity of the framework's guidance, the automation
scripts in [`scripts/`](scripts/), and the supply chain of any tooling the framework
recommends.

## Reporting a concern

If you discover a vulnerability in the framework's scripts or tooling, or content
that could lead engineering teams to build insecure platforms, please report it
privately.

- **Contact:** Willian Borges — via the repository's private security advisory
  channel, or the maintainer's listed contact.
- Please do not open a public issue for undisclosed security concerns.

## What to include

- A description of the issue and its potential impact.
- Steps to reproduce or the specific document/section affected.
- Any suggested remediation.

## Response

We aim to acknowledge reports within a reasonable time, assess impact, and publish
a correction or advisory. Security guidance for platforms built *with* APEF lives in
[`handbook/15-security/`](handbook/15-security/) and
[`specifications/security/`](specifications/security/).
