# Architecture — Event Storming

## Overview
Holds event-storming outputs that explore the platform's domain through the flow of domain events, commands, and reactions.

## Purpose
To surface the domain's behavior as an architectural activity.

## Responsibilities
- Hold the event storming for the reference platform as diffable diagram-as-code.
- Stay consistent with the architecture requirements.

## Contents
- Event-storming boards, domain-event catalogs, and the models derived from them.
